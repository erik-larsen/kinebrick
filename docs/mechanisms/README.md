# Mechanisms

The kinds of mechanism in LEGO Technic sets: when each first appears, and how often it's used since, from the 1224 functions of the 186 sets Kinebrick Play has surveyed so far (1977 to 2021). Each function's kinds are tagged from what its building instructions show it doing. Generated by `npm run mechanisms` (`scripts/mechanisms.ts`) from the kinds in [data/mechanisms.json](../../data/mechanisms.json) and the `mechanisms` of each function in [data/sets/](../../data/sets/README.md); don't edit it by hand.
