# Packed models

Each `.mpd` file here is one of the test models in `../models/`, packed together with every LDraw part and primitive it uses, so the viewer needs no LDraw parts library. `titles.json` holds the LDraw title of every part the models use. Generated by `scripts/pack-models.ts` (`npm run pack`); don't edit by hand.

The parts and primitives come from the [LDraw parts library](https://library.ldraw.org), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see the authors named in each part's header.
